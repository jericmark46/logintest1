Local dev runs two separate processes: `cd backend && npm run dev` (port 5000) and `cd frontend && npm run dev` (port 5173), each requiring its own `.env` copied from `.env.example`. Deployment requires two Vercel projects pointing at the same Git repo with `Root Directory` set to `backend` and `frontend` respectively, plus shared env vars (`MONGODB_URI`, `JWT_SECRET`, `CLIENT_ORIGIN`, `VITE_API_URL`).
